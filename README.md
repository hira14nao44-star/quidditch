# クィディッチ

ブラウザで遊べる 4対4 の3Dクィディッチ（ファンメイドの身内用ゲーム）。

**遊ぶ: https://hira14nao44-star.github.io/quidditch/**

- パソコン（マウス＋キーボード）向け
- 1人で遊ぶ（ボット相手）／みんなで遊ぶ（オンライン 1〜6人）

## みんなで遊ぶ（オンライン）

1. 誰か1人が「みんなで遊ぶ」→ 名前を入れて「部屋を作る」
2. 出てきた **部屋コード** か **招待リンク** を友達に送る
3. 友達はリンクを開くかコードを入れて「入る」
4. ロビーで入りたい枠（チェイサー／ビーター）の「ここに入る」を押す
5. 部屋を作った人がチームとステージを決めて「試合開始」

空いている枠とキーパーはボットが担当します。

## 操作

マウスで向き / WASD で移動 / Q でブースト / Space で回避ロール / 左右クリックでアクション / Esc でポーズ

ゲーム本体は `index.html` です（Three.js・PeerJS を CDN から読み込み）。ストーリー画像は `img/`、オリジナルBGMはオリジナル曲で、大作映画風のオーケストラです（メニュー・試合・終盤・ストーリーの会話・試合前・勝利後の6曲）。全曲に共通の主題があり、試合では短調で勇ましく、勝利の場面では長調で鳴ります。曲と6種類の短い演出音は録音済みで、ゲーム中の音符合成は行いません。楽譜と録音用コードは `tools/build-theme-music.py`、音源クレジットは `audio/CREDITS.md` にあります（これらのコードはゲームからは読み込みません）。

BGMは魔法学校風のオリジナル曲です。メニューはチェレスタ・ハープ・弦・木管を中心に、試合は実楽器サンプルによる三拍子の旋律、渦を巻く弦、ホルンと金管、チェレスタを中心にしています。試合曲は148 BPM、終盤曲は166 BPMで、途中に静かな橋渡しとクレッシェンドを置き、後半で主題が大きく戻る構成です。曲と6種類の短い演出音は録音済みで、ゲーム中の音符合成は行いません。楽譜と録音用コードは `tools/music-score.js` と `tools/build-match-music.py`、音源クレジットは `audio/CREDITS.md` にあります（これらのコードはゲームからは読み込みません）。

ローカルで確認する場合は、このフォルダで `python -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765/` を開いてください。
