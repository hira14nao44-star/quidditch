# クィディッチ

ブラウザで遊べる 4対4 の3Dクィディッチ（ファンメイドの身内用ゲーム）。

**遊ぶ: https://hira14nao44-star.github.io/quidditch/**

- パソコン（マウス＋キーボード）向け
- 1人で遊ぶ（ボット相手）／みんなで遊ぶ（オンライン 1〜6人）

## みんなで遊ぶ（オンライン）

1. 誰か1人が「みんなで遊ぶ」→ 名前を入れて「部屋を作る」
2. 出てきた **部屋コード** か **招待リンク** を友達に送る
3. 友達はリンクを開くかコードを入れて「入る」
4. ロビーで入りたい枠（チェイサー／ビーター）の「ここに入る」を押す
5. 部屋を作った人がチームとステージを決めて「試合開始」

空いている枠とキーパーはボットが担当します。

## 操作

マウスで向き / WASD で移動 / Q でブースト / Space で回避ロール / 左右クリックでアクション / Esc でポーズ

`index.html` 1ファイルで動きます（Three.js・PeerJS を CDN から読み込み）。
